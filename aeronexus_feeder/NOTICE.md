# 출처와 변경 범위

사용자가 참조 대화에서 제공한 `붙여넣은 텍스트(1).txt`를 입력 원본으로 사용했습니다.
이전 대화의 `/mnt/data/붙여넣은 텍스트(1).txt`는 현재 작업에서는 참조 대화 첨부파일을 통해 읽었습니다.
제목이나 이전 답변의 추정만으로 새 프로토콜을 만든 것이 아닙니다.

- 업로드 원본 크기: 44,771바이트.
- 업로드 원본 SHA-256:
  `57e2d8c11805a09407d018ce606a7b393e2250ae7f771a816d8777e6f7f677d6`
- 원본의 `PYEOF` here-document 안 Python 중계기 344줄을
  `upstream/feed_relay.original.py.txt`에 보관했습니다(UTF-8/LF, 실행 빌드에는 제외).
- 서버 주소 `aeronexus.kr:30004`, UUID 프레임 `1A E4 + ASCII 36자`, Beast 심장박동,
  DF17/18 필터, MLAT timestamp 제외는 이 입력 원본을 기준으로 유지했습니다.
- `beast.py`의 Splitter는 원본에서 추출한 파서를 사용합니다. E3 receiver-id의
  잘못된 escape를 다음 프레임 경계로 복구하는 보완이 들어갔습니다.
- HA용 실행기 `relay.py`, 설정/UI, S6/Docker, 테스트, 가이드를 추가했습니다.

HAOS 컨테이너에서는 원본의 호스트 탐색, systemd 유닛 작성, `/etc/default` 설정,
FR24 파일 수정 절차를 실행하지 않습니다. 원격 `feed.sh`를 시작 때 다시 내려받아 실행하지 않습니다.
이 패키지는 AeroNexus 운영자가 발행하거나 승인한 공식 Home Assistant 앱이라는 의미가 아닙니다.

원본 배포 허락은 저장소 소유자가 원본 권리자에게 받았다고 확인했습니다.
이 저장소는 그 허락에 따라 공개 배포하도록 준비했습니다. 별도 라이선스를 임의로 부여하거나
원본의 권리를 변경하지 않습니다.

1.1.0부터 원본의 Python 중계기 전체를 공식 HTTPS 서버에서 검사/업데이트합니다.
이미지의 bundled_relay.py는 네트워크 장애 시 초기 코드입니다. 원본 shell 설치기는 실행하지 않습니다.
기존 beast.py/relay.py 전송기는 1.0 회귀 검사 및 HA 설정/탐색 공용 함수로 남겨두었습니다.
