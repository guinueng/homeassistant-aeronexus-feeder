# Changelog

## 1.1.3

- 운영팀 피드백 반영: UUID 하나는 기기 하나에서만 사용, 이전 파이의 피더를 먼저 제거하도록 안내.
- UUID 설정 UI·앱 소개·문서에 중복 접속 시 나중에 접속한 쪽이 끊긴다는 설명과 --uninstall 이전 절차 추가.
- 서버 연결 후 10초 이내 EOF/reset/broken pipe에 UUID 중복 사용 가능성 경고. 반복 경고는 60초에 한 번.
- 수신기 끊김/시간 초과/로컬 종료 구분, 원본 Python·전송 바이트·재접속 동작 유지.
- 모의 소켓과 실제 공식 중계기 프로세스로 감지·오탐 방지·경고 수준·UUID 비노출 검사 추가.

## 1.1.2

- 구성에 다음 시작 시 최신 중계기 받기 옵션 추가.
- 같은 앱 버전에서도 공식 코드를 수동 갱신. 성공 시 자기 옵션을 자동으로 해제.
- 기존 UUID/Beast 설정과 !secret 참조 보존. 주기 확인 없음 유지.
- 수동 요청/자동 해제/API 실패/비밀값 로그 회귀 검사 추가.

## 1.1.1

- 매시간 공식 코드 확인 제거. 최초 실행/새 앱 버전 첫 실행에만 한 번 확인.
- 성공 상태를 저장하여 일반 재시작/재부팅 후에도 코드 버전을 유지.
- 최초 다운로드 실패는 실행 중 재시도하지 않고 다음 재시작 시 한 번 재시도.
- 1.1.0 update_interval 옵션은 호환용으로 받아 무시.
- 확인 주기·재시작·버전 변경·후보 복구 회귀 검사 추가.

## 1.1.0

- 시작 시/기본 매시간 공식 feed.sh 확인, Python 중계기 전체 다운로드/호환성 검사/자동 적용.
- 일반 사용자 프로세스 실행, 부모 인증 환경 분리, UUID 로그 숨김.
- 조건부 요청, SHA 코드 버전, 영구 캐시, 초기 실행 실패 시 이전 버전 복구.
- 공개 저장소 추가 버튼과 최신 GitHub 소스를 받는 Terminal 설치기.
- 업데이트/마이그레이션/백업 가이드 갱신. 43개 테스트와 두 아키텍처 이미지 빌드 검증.

## 1.0.0 — 2026-10-31

- 제공된 feed.sh의 Python Beast 중계기를 Home Assistant 로컬 앱으로 구성.
- UUID 구성 UI, 빈 UUID 대기, 한국어/영어 번역.
- 기존 ADS-B Multi-Portal Feeder 자동 탐색 및 직접 주소 지정.
- DF17/18 필터, MLAT 표식 제외, UUID/심장박동 프로토콜 유지.
- 소켓 타임아웃, 독립 재접속, 단조 시간 타이머, 실제 쓰기 기준 통계.
- S6 서비스, 부팅 자동 시작, Supervisor 로그·백업 안내.
- 원본 receiver-id E3 처리의 잘못된 escape 복구 보완.
- 로컬 TCP 모의 서버를 포함한 회귀 검사, 경로/설치/편집/백업 문서 제공.
