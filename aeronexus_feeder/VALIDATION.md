- 사용자의 실제 HAOS Supervisor에서 앱 설치, 내부 DNS/마운트, UI 조작.
- 실제 UUID로 AeroNexus 자료 수신/승인/지도 노출.
- 실제 HAOS 재부팅/백업 복원.
- 원본의 미래 모든 변경에 대한 호환성. 검증에 실패하면 이전 버전을 유지하도록 설계했습니다.

Docker 빌드는 이미지 구성이 맞는지 확인한 것이며 실제 HAOS 설치 완료를 뜻하지 않습니다.
