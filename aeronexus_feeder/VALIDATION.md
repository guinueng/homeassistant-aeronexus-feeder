# 1.1.5 검증 결과

- Windows와 Ubuntu(WSL)의 Linux Python에서 각각 91개 회귀 검사 통과.
- 실행용 동봉 중계기 부재, 공식 다운로드 이력 없는 기존 캐시 거부, 출처 URL 검증 확인.
- 매 갱신 요청의 공식 HTTPS URL·전체 본문 다운로드·동일 ETag/날짜의 실제 코드 변경 검출 확인.
- 최초 다운로드 실패 시 중계/Beast 탐색 미실행 및 실행 중 반복 다운로드 없음 확인.
- 첫 공식 다운로드 실행·30초 후 적용, 코드 변경 교체, 설치기만 변경될 때 재시작 생략 확인.
- 받은 원문 보관, 잘못된 원본 수신 시 기존 정상 캐시/원문 보존, 비정상 HTTP 304 거부 확인.
- 정상 캐시 없는 후보 실행 실패 시 동봉본 대체 실행 없음 확인.
- UUID 중복 의심 시 종료·재접속 차단·Supervisor 중지 요청 및 실패 시 대기 정책 유지.
- 실제 공식 표본의 UUID/Beast/DF17/18/MLAT 동작, 정상 캐시 복구·설정 보존·비밀값 비노출 검사 유지.
- 공식 서버에 시험용 ADS-B 자료나 UUID를 전송하지 않음. 원본 shell 설치기 실행 없음.
- 로컬 Docker 엔진이 시작되지 않아 1.1.5 이미지 빌드는 미완료. Dockerfile의 실행 의존성은 기존과 동일.
- YAML, 번역, UTF-8/LF, 원본 표본 해시, 문서 링크, 파일 목록 및 ZIP 내용 검사.

공식 서버의 현재 실시간 응답과 실제 HAOS의 다운로드·앱 중지·Watchdog·백업 복원은 미실측입니다.
직접 다운로드/비교/교체는 모의 HTTPS 응답 및 실제 공식 표본 중계기로 검증했습니다.
